# 琥珀核心：昆蟲生態格鬥

16 種真實昆蟲與小動物的 2D 橫向格鬥遊戲，單一 `index.html`，不需安裝任何東西。

## 怎麼玩

- **本機**：在這個資料夾執行 `python3 -m http.server`，再開 <http://localhost:8000>。（直接雙擊 `index.html` 也能玩，只是 P2 色違圖會改用瀏覽器濾鏡。）
- **線上**：GitHub repo → Settings → Pages → Branch 選 `main` / root，存檔後就有網址可以分享。

## 模式

1P 對戰 CPU（簡單／普通／困難）、2P 本機對戰、練習模式。三戰兩勝，每回合 99 秒。

## 操作

| 動作 | P1 鍵盤 | P2 鍵盤 | 手把 |
|---|---|---|---|
| 移動／跳／蹲 | A D / W / S | ← → / ↑ / ↓ | 搖桿／十字鍵 |
| 輕攻擊 | J | Numpad1 或 `,` | A |
| 重攻擊 | K | Numpad2 或 `.` | B |
| 必殺技 | L | Numpad3 或 `/` | X / RB |
| 超必殺／EX | U | Numpad4 或 右Shift | Y / RT |
| 暫停 | Esc / P | — | Start |

手機橫放：左下虛擬搖桿、右下四顆按鈕，點上方計時器暫停。

## 戰鬥系統

- **防禦**：按住後方向。站著擋不了蹲重攻擊（下段），蹲著擋不了跳躍攻擊（上段）。
- **連段**：輕 → 重 → 必殺，命中時可以取消接下一招。
- **投技**：近距離同時按輕＋重，無法防禦。
- **能量條（3 格）**：1 格放 EX 必殺（無敵、更強），3 格放超必殺（全螢幕演出、多段攻擊）。
- 角色分成五種類型：速度型、力量型、平衡型、遠距型、空中型。
- F1 開啟判定框顯示（除錯用）。
